# **在做科学的过程中学习科学。**

Kepler 是一个开放的教育与研究项目，以肉眼天文学为途径，通过可复现的观测研究来教授科学测量与计算科学——从统计推断直到现代机器学习与人工智能。

参与者用廉价材料制作简易的天文仪器，观测夜空，并把这些观测汇入一个不断增长的共享数据集。这些测量成为探索各类推断方法的基础，同时也培养起可复现科学研究的实践习惯。

本项目的终点不只是模型或预测，而是科学解释。参与者评估相互竞争的假说，传达证据，并撰写论证自身结论的科学文字。许多研究会邀请参与者以现代证据标准重新检视历史上的天文学主张，从观测出发得出自己的结论，而不是复述既定的叙述。

> **我们如何从不完美的观测中，推断出世界隐藏的结构？**

# 什么是 Kepler？

Kepler 支持两种互补的科学研究形式。

基础性研究（foundational investigations）通过对天空的引导式考察来培养观测技能。

主张性研究（claim investigations）邀请参与者用自己设计的研究，去评估具有历史意义的科学主张。

------------------------------------------------------------------------

# 为什么要有 Kepler？

现代科学教育常把科学知识呈现为一批既定事实的集合。Kepler 采取不同的进路。

参与者把科学作为一个过程来经历：

- 制作仪器，
- 进行测量，
- 刻画不确定度，
- 汇集证据，
- 比较相互竞争的模型，
- 完善解释。

本项目强调：不确定度不是科学的缺陷——它正是科学理解得以构建的原材料。

# 项目理念

每一次观测都始于真实世界，终于一次推断。

``` text
太阳系
      ↓
可观测的天空
      ↓
仪器
      ↓
观测者
      ↓
测量
      ↓
数据集
      ↓
推断
      ↓
科学理解
      ↓
科学传达
```

科学理解只有在能够被他人传达、审视与复现之后，才算完整。

本仓库的每一个组成部分，都是为了支撑上述过程中的某一个或某几个环节而存在的。

关于这一概念框架的完整讨论，参见：

- [`docs/measurement-model.md`](docs/measurement-model.zh.md)

# Kepler 的不同之处是什么？

许多天文项目教的是天文学。

许多统计课程分析的是现成的数据集。

许多机器学习课程的起点，是已经清洗与整理好的数据。

Kepler 的起点要早得多。

参与者自己创造数据。

本项目把整个测量过程本身当作研究对象。仪器各不相同。观测者各不相同。条件各不相同。这些差异不是需要消除的问题——它们是可供建模的信息。

这使得本项目成为研究以下课题的天然环境：

- 测量误差
- 不确定度量化
- 层次模型
- 模拟
- 因果推理
- 模型比较
- 可复现的科学工作流

# 项目目标

Kepler 有四个互补的目标。

## 1. 教授科学测量

参与者学习观测是如何被产出、校准与评估的。

## 2. 构建开放的天文数据集

跨多轮课程收集的观测，汇成一个不断增长的纵向数据集，可同时用于研究与教学。

## 3. 比较各类推断方法

本仓库的设计支持多种推断进路，包括：

- 描述统计
- 回归
- 混合效应模型
- 贝叶斯推断
- 状态空间模型
- 高斯过程
- 监督学习
- 无监督学习
- 深度学习

没有任何单一框架被视为"正确"的进路。

## 4. 推动可复现研究

项目的所有方面——包括仪器设计、观测协议、数据模式、模拟、推断方法、研究、工作流与软件——都纳入版本控制并公开记录。

# 当前状态

Kepler 正处于活跃的早期开发阶段。

仓库目前已包含：

- 一套完整的十字杆（cross-staff）仪器设计与制作指南，
- 一份经过校验的校准观测调查，
- 初版数据规范与 JSON 模式，
- 观测调查校验工具，
- 贡献者文档。

随着更多仪器、观测协议、数据集、模拟与教学材料的开发，项目将持续演进。

仓库中已包含初版数据契约的完整参考实现，其中包括一份经过校验的十字杆校准观测调查。

开发优先级与更长期的里程碑仍在确定之中。

# 致谢

Kepler 的灵感来自数百年的观测天文学，尤其是第谷·布拉赫与约翰内斯·开普勒的工作——他们对审慎测量的坚持，改变了我们对太阳系的理解。

他们的工作提醒我们：科学革命的开端不是确定性，而是那些恰好精确到足以揭示"我们现有解释并不完整"的观测。
