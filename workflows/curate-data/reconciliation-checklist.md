# Kepler Data Reconciliation Checklist

Use this checklist after creating a working dataset from the original field record and before beginning curation.

The purpose of reconciliation is to verify that the working dataset faithfully represents the original observations.

## Inputs

* [ ] Original field dataset available.
* [ ] Working dataset available.

## Observation Integrity

* [ ] Observation count verified.
* [ ] No observations omitted.
* [ ] No observations duplicated.
* [ ] Observation order preserved (or intentional reordering documented).

## Scientific Measurements

* [ ] All recorded measurement values preserved.
* [ ] All recorded units preserved.
* [ ] No scientific values modified.
* [ ] No derived quantities introduced.

## Observation Context

* [ ] Target/reference names preserved.
* [ ] Dates preserved.
* [ ] Times preserved.
* [ ] Notes preserved (if applicable).

## Structural Changes

* [ ] Structural changes documented.
* [ ] Column renaming documented.
* [ ] Identifier additions documented.
* [ ] Timestamp formatting documented.
* [ ] Blank rows removed (if applicable).

## Reconciliation Log

* [ ] `reconciliation.log` created or updated.
* [ ] Working observation format version recorded.
* [ ] Result recorded (PASS/FAIL).

## Ready for Curation

* [ ] Dataset is ready for curation.
