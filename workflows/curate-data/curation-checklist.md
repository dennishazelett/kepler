# Kepler Data Curation Checklist

Use this checklist after **reconciliation** and before **analysis**.

The purpose of curation is to enrich a reconciled working dataset with stable contextual information while preserving the original scientific observations.

## Dataset

* [ ] Dataset identifier assigned.
* [ ] Dataset purpose documented.
* [ ] Dataset status recorded.

## Observer

* [ ] Observer identifier assigned.

## Instruments

* [ ] Instrument instance identifier(s) assigned.
* [ ] Instrument photographs or supporting documentation attached if available.

## Site

* [ ] Observing site identifier assigned.
* [ ] Site coordinates recorded.
* [ ] Site metadata created or updated if necessary.

## Observation Context

* [ ] Stable target/reference identifiers assigned where appropriate.
* [ ] Dates and times standardized.
* [ ] Measurement units confirmed.
* [ ] No scientific measurements altered.

## Calibration Context (if applicable)

* [ ] Calibration geometry documented.
* [ ] Reference objects documented.
* [ ] Experimental setup sufficiently described for later reproduction.

## Supporting Metadata

* [ ] Required supporting metadata files created or updated.
* [ ] Attachments organized and referenced.

## Curation Log

* [ ] `curation.log` created or updated.
* [ ] All contextual additions recorded.
* [ ] Scientific measurements confirmed unchanged.

## Ready for Analysis

* [ ] Dataset is ready for exploratory analysis.
