# 象限仪校准规程

**规程 ID：** `quadrant-calibration` **规程版本：** `0.1.0` **状态：** 草案

------------------------------------------------------------------------

# 目的

本规程描述一套标准化流程，用于刻画"观测者—象限仪"这一测量系统在受控条件下的表现。

观测者测量校准目标的几何参数，并记录象限仪读数。随后，参考角度由测得的目标高度、观测者距离，以及目标相对于视线高度的高度推断得出。在分析阶段，这些推断出的角度将与象限仪读数进行比较。

校准记录的是测量表现；它不修改、也不修正后续的观测。

------------------------------------------------------------------------

# 适用范围

本规程适用于使用 Kepler 象限仪执行的校准观测调查。

它适用于仪器的初始表征、维修后验证、教学练习与周期性性能检查。

本规程不适用于天文野外观测。

------------------------------------------------------------------------

# 科学问题

> 由这套"观测者—仪器"系统得到的象限仪读数，与依据独立测得的校准几何推断出的角度相比，表现如何？

------------------------------------------------------------------------

# 所需器材

- Kepler 象限仪

<!-- -->

- 5 个校准目标，从视线高度起、以 1 英尺（或 0.3 米）为间隔布置

- 适于测定观测者水平距离的量具

- 适于测定目标高度与视线高度的量具

- 记录材料或电子数据采集设备

- 适用的象限仪校准观测规范

------------------------------------------------------------------------

# 前置条件

开始校准观测调查之前：

- 象限仪应已完整且机械功能正常；

- 铅垂线应能自由摆动、无阻碍；

- 观测者应熟悉象限仪的常规操作；

- 在采集与某一几何配置相关的观测期间，观测者位置与校准目标应保持固定；并且

- 所需的距离与高度应能独立于象限仪之外测得。

------------------------------------------------------------------------

# 观测流程

对校准目标上每一个标记出的参考点：

1.  确定观测者位置与校准目标。

2.  按适用观测规范的要求，测量并记录校准几何参数。

3.  用象限仪照准该标记参考点。

4.  等待铅垂线稳定。

5.  照实记录象限仪读数。

6.  在开始下一次观测之前，把象限仪从目标上移开放下。

7.  重复第 3–6 步，直到对同一参考点记录满**五次独立观测**。

8.  对其余每一个标记参考点重复上述过程。

9.  每当观测者位置、目标位置、视线高度或其他相关布置几何发生变化时，重新测量几何参数。

除非参考角度是作为源测量直接提供的，否则不得把它们录入规范观测表。由记录的几何参数计算出的角度属于派生量，应放在后续分析中。

------------------------------------------------------------------------

# 数据要求

依本规程产出的观测应符合适用的象限仪校准观测规范。

该观测规范定义了：

- 必需的观测字段；
- 字段语义；
- 规范表示形式；
- 允许的数据类型；以及
- 必需的元数据。

本规程不重新定义这些要求。

------------------------------------------------------------------------

# 质量控制

观测者应当：

- 确认仪器在整个观测调查过程中保持机械稳定；
- 在读数记录完成前避免扰动铅垂线；
- 确保每一次观测都对应一次有意为之的单独测量；
- 直接记录观测，不做事后追忆式的重建；以及
- 记录任何影响测量质量的异常情况。

> 相继的观测应当代表相互独立的测量尝试。观测者不应从一次仪器对准中记录多个读数。只要实际可行，对同一参考点的观测应与对其他参考点的观测交错进行。当必须对同一参考点连续观测时，每次观测之前都应把象限仪完全放下并重新对准。

如果某次观测在合理判断下不可信，仅当其具体情形被完整记录时才予以保留。否则应重做测量，并记录替代的那次观测。

------------------------------------------------------------------------

# 偏离规程

偏离本规程并不自动使一次观测调查失效。

任何可能影响解读的偏离，都应记入观测调查的备注中，并包含足以供日后复核的信息。

例如：

- 器材故障；
- 环境干扰；
- 校准几何的变更；
- 观测序列被打断；以及
- 数据采集过程中察觉到的观测者失误。

------------------------------------------------------------------------

# 预期产出

依本规程产出的观测调查应包含：

- `survey.json`
- 一份或多份符合适用观测规范的象限仪校准观测表；
- `notes.csv`（如适用）；
- 配套附件（如适用）；以及
- 所需的溯源信息。
