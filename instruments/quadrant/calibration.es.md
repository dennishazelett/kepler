# Calibración del Cuadrante

Antes de utilizar un cuadrante para realizar observaciones científicas, el sistema completo observador–instrumento debe someterse a una campaña de calibración documentada.

La calibración caracteriza el desempeño del sistema completo observador–instrumento bajo condiciones controladas. Proporciona la base empírica para comprender la exactitud, la precisión y la repetibilidad de las mediciones.

Kepler separa la justificación científica de la calibración de los procedimientos utilizados para llevarla a cabo. Los siguientes documentos describen el flujo de trabajo recomendado para la calibración y proporcionan el material de referencia correspondiente.

La calibración mide el desempeño del sistema completo observador–instrumento. No ajusta el instrumento ni modifica las observaciones posteriores. En cambio, proporciona la evidencia necesaria para comprender el desempeño del instrumento e interpretar correctamente las mediciones futuras.
