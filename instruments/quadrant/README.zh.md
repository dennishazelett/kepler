# 象限仪

象限仪是 Kepler 项目中的第二件参考仪器。

十字杆通过线性测量与几何重建来估计角距，象限仪则不同——它用一段刻度弧与一条铅垂线直接测量仰角。两件仪器合在一起，展示了天文测量中两条互补的路径，也提供了比较它们在精度、准确度、校准需求与误差特性上差异的机会。

象限仪意在同时支撑历史性研究与现代科学实践。虽然它的灵感来自历史仪器，但目标并非为复原而复原。这件仪器真正的作用，是作为一个载体，用来研究审慎的观测、校准、不确定度分析与统计推断如何共同产出科学知识。

## 学习目标

制作与使用象限仪，会让参与者接触到：

- 直接角度测量
- 以重力作为测量基准
- 刻度仪器的校准
- 观测不确定度
- 仪器之间的比较
- 可复现的数据收集

这些概念与十字杆所引入的概念互为补充，拓宽了 Kepler 中可用的观测技术范围。

## 与 Kepler 数据模型的关系

象限仪是对 Kepler 所设计的仪器无关架构的第一次检验。

观测调查的元数据、校验工作流与仓库组织方式预期保持不变。只有与仪器相关的观测模式应当与十字杆有所不同。

这提供了一个机会，用来评估 Kepler 数据模型是否成功地把通用的观测概念，与特定仪器的测量细节分离开来。

## 当前状态

Kepler 参考象限仪已完成设计、制作，并通过一轮初始校准活动完成了评估。

当前工作聚焦于完善校准规程、记录仪器性能，并把仪器的应用从受控的校准测量扩展到天文野外观测。
