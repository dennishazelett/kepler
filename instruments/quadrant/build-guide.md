# Quadrant Build Guide

This document describes the construction of the Kepler reference quadrant.

The objective is to produce an inexpensive, robust, and repeatable instrument suitable for astronomical observation and educational use. Historical authenticity is considered only insofar as it supports the project's educational goals.

The build described here is expected to evolve as additional prototypes are constructed and evaluated.

------------------------------------------------------------------------

# Design Objectives

The completed instrument should be:

- inexpensive
- easy to construct using common tools
- mechanically robust
- easy to calibrate
- comfortable to use
- sufficiently accurate for scientific investigation

Preference is given to simplicity and repeatability over historical fidelity.

------------------------------------------------------------------------

# Candidate Materials

The following materials are currently under consideration.

## Structure

Possible options include:

- plywood
- hardwood
- MDF
- acrylic sheet
- aluminum plate

Selection criteria include stiffness, dimensional stability, weight, and ease of machining.

## Angular Scale

Possible approaches include:

- printed paper scale
- laminated printed scale
- adhesive measuring tape
- engraved scale

The chosen approach should balance readability, durability, and ease of replacement.

## Sighting Mechanism

Candidate designs include:

- simple pin sights
- notch-and-post sights
- narrow viewing slot
- tube sight

The final design should prioritize repeatability over magnification.

## Plumb Line

Candidate materials include:

- braided nylon line
- fishing line
- fine cord

Possible weights include:

- brass weight
- steel nut
- machined plumb bob

The plumb line should hang freely with minimal oscillation.

# Construction Overview

The build process is expected to follow these general steps:

1.  Prepare the structural body.
2.  Construct or attach the graduated quadrant.
3.  Install the sighting mechanism.
4.  Install the plumb-line pivot.
5.  Attach the plumb line and weight.
6.  Verify mechanical alignment.
7.  Perform calibration.

Detailed instructions will be added after the first prototype has been constructed.
