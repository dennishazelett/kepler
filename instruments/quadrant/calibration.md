# Quadrant Calibration

Before using a quadrant for scientific observations, the instrument should undergo a documented calibration campaign.

Calibration characterizes the performance of the complete observer–instrument system under controlled conditions. It provides the empirical basis for understanding measurement accuracy, precision, and repeatability.

Kepler separates the scientific rationale for calibration from the procedures used to perform it. The following documents provide the recommended calibration workflow and supporting reference material.

Calibration measures the complete observer–instrument system. It does not adjust the instrument or alter subsequent observations. Instead, it provides the evidence needed to understand the instrument's performance and interpret future measurements.
