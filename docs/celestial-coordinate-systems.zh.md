# 天球坐标系

## 目的

要进行科学观测，我们必须能够描述一个天体在天空中出现的位置。

天球坐标系为记录这些位置提供了一套共同的语言。

理解这些坐标系至关重要，因为天文仪器并不测量"坐标"。它们测量的是可观测量，而坐标是由这些量推断出来的。

------------------------------------------------------------------------

# 问题

假设有人指着一颗亮星说：

> "就在那边。"

这个描述只对同一时刻站在同一地点的人才有意义。

科学观测需要的是一种能够被传达、复现，并在不同观测者之间相互比较的描述。

坐标系解决的正是这个问题。

------------------------------------------------------------------------

# 天球

天球是一个以观测者为中心、半径任意大的假想球面。

每一个可见的天体都被投影到这个球面上。

尽管恒星的距离相差极为悬殊，但在描述方向时，它们都表现为天球上的点。

因此天球是一个几何模型，而不是一个物理实体。

------------------------------------------------------------------------

# 地平坐标系

最直观的坐标系以观测者为基准。

用两个坐标即可描述任何可见天体。

## 高度角

高度角是天体在当地地平线以上的角度。

- 地平线 = 0°
- 天顶（正上方）= 90°

高度角回答的是：

> 这个天体在地平线以上多高？

------------------------------------------------------------------------

## 方位角

方位角度量的是沿地平线一圈的方向。

它回答的是：

> 我应该朝哪个方向看？

具体的约定各有不同，但 Kepler 将对所有观测采用同一套公开发布的约定。

------------------------------------------------------------------------

## 优点

- 容易理解。
- 与观测行为直接对应。
- 对许多简易仪器而言是自然的选择。

------------------------------------------------------------------------

## 局限

地平坐标系依赖于：

- 观测者所在位置；
- 观测时刻。

随着地球自转，每一个天体的坐标都在持续变化。

因此同一颗恒星在一夜之中会有不同的地平坐标。

------------------------------------------------------------------------

# 赤道坐标系

天文学家常常需要一种不依赖观测者当地地平线的坐标系。

为此，他们把地球的自转轴与赤道投影到天球上。

由此得到赤道坐标系。

------------------------------------------------------------------------

## 赤纬

赤纬类比于地理纬度。

它度量一个天体位于天赤道以北或以南多远。

赤纬以度为单位。

------------------------------------------------------------------------

## 赤经

赤经类比于地理经度。

它传统上不以度、而以时、分、秒为单位。

24 小时的赤经对应绕天赤道整整一周。

------------------------------------------------------------------------

## 优点

与地平坐标不同，在通常的观测时间尺度上，天体的赤道坐标基本保持不变。

它们为天文星表与星图提供了共同的参考系。

------------------------------------------------------------------------

# 仪器与坐标

不同的天文仪器测量不同的物理量。

例如：

| 仪器        | 直接测量的量                  |
|-------------|-------------------------------|
| 十字杆      | 角距                          |
| 象限仪      | 高度角                        |
| 圭表        | 由影长几何得到的太阳高度角    |
| 望远镜      | 指向方向                      |

这些测量本身并不是天球坐标。

它们提供的是可用于推断天球坐标的信息。

------------------------------------------------------------------------

# Kepler

Kepler 关注的是完整的科学过程。

本项目并不从天球坐标出发，而是从观测出发。

```text
天空
    ↓
仪器
    ↓
测量
    ↓
坐标推断
    ↓
科学推断
```

理解测量如何变成坐标，是本项目的核心主题之一。

后续文档将描述把原始观测与天球坐标系联系起来的几何关系、校准流程与推断方法。
