# Scientific Questions

## Purpose

Kepler is organized around scientific questions rather than software, statistical methods, or educational technologies.

These questions define the intellectual purpose of the project and provide a stable foundation upon which instruments, protocols, software, datasets, simulations, and course materials can evolve.

The project intentionally avoids committing to particular inferential methods. Instead, it seeks to understand how different approaches help answer meaningful scientific questions using observations collected by participants.

------------------------------------------------------------------------

# Central Question

**How can careful observations made with simple instruments be transformed into reliable scientific knowledge?**

Everything in Kepler exists in service of this question.

------------------------------------------------------------------------

# Theme I — Observation and Discovery

## Can participants independently recover fundamental astronomical truths?

Modern learners are taught that:

- the Earth orbits the Sun;
- the planets follow predictable paths;
- planetary orbits are elliptical;
- planetary motion can be described mathematically.

Kepler asks a different question:

**Can participants verify these statements using observations they make with their own instruments?**

Rather than accepting scientific knowledge solely through authority, participants are invited to reconstruct portions of that knowledge from evidence. Science tells us a story about the motion of the planets around the sun, but this story is nearly impossible to have any intuition for in our everyday lives. After all, what is a planet, really? Without meticulous observation, the planets in our solar system appear to us as little different than the brightest stars. One of the central educational goals of the project is to make such observations and retrace the steps of Tycho Brahe and Johannes Kepler, to ask—as scientists have done for ages—are these results reproducible? Are the conclusions verifiable?

------------------------------------------------------------------------

## How much evidence is enough?

Scientific conclusions rarely emerge from a single observation.

Questions include:

- How many observations are required before planetary motion becomes apparent?
- Which observations contribute the greatest amount of information?
- What features become visible first?
- When does the evidence become convincing?

------------------------------------------------------------------------

# Theme II — Measurement

## What limits the quality of observations?

Every observation is influenced by:

- instrument design;
- calibration;
- observer experience;
- environmental conditions;
- recording procedures.

Questions include:

- Which sources of uncertainty dominate?
- Which are systematic?
- Which are random?
- Which can be reduced through improved protocols?

------------------------------------------------------------------------

## How much precision is actually necessary?

Tycho Brahe achieved remarkable accuracy without telescopes.

Kepler asks:

- How much precision is required to recover planetary motion?
- What scientific questions can be answered using inexpensive handmade instruments?
- Which questions require greater precision?

------------------------------------------------------------------------

# Theme III — Human Learning

## How do people become better observers?

Observation is a learned skill.

Questions include:

- How does observer performance change with experience?
- Which forms of feedback improve measurement quality?
- Does calibration improve accuracy or consistency?
- How quickly do beginners approach expert performance?

------------------------------------------------------------------------

## How do observers differ?

Participants will inevitably produce different measurements under identical conditions.

Questions include:

- How large is observer-to-observer variation?
- Can consistent biases be identified?
- Which characteristics predict reliable observations?
- How should multiple observers be combined?

------------------------------------------------------------------------

# Theme IV — Collective Science

## Can many simple measurements outperform a few precise ones?

One of the project's central hypotheses is that collective observation can compensate for individual uncertainty.

Questions include:

- How should measurements be aggregated?
- How much information is gained by pooling observations?
- When does increasing the number of observers produce diminishing returns?

------------------------------------------------------------------------

## What emerges from long-term observation?

Because observations accumulate across multiple course offerings, entirely new questions become possible.

Examples include:

- seasonal effects;
- long-term instrument evolution;
- observer learning over years;
- improvements in protocols;
- changes in dataset quality.

------------------------------------------------------------------------

# Theme V — Statistical Inference

## Which statistical models best explain the observations?

The project encourages comparison among competing approaches.

Questions include:

- Which models best characterize measurement uncertainty?
- When are hierarchical models beneficial?
- What assumptions matter most?
- How sensitive are conclusions to modeling choices?

------------------------------------------------------------------------

## How should uncertainty be represented?

Questions include:

- What information is lost by reporting only point estimates?
- How should uncertainty be communicated?
- Which visualizations best support scientific reasoning?

------------------------------------------------------------------------

# Theme VI — Machine Learning

## Which machine learning methods recover latent structure most effectively?

Machine learning provides alternative ways to understand the data.

Questions include:

- Can supervised learning recover planetary trajectories?
- Can unsupervised learning identify observer or instrument clusters?
- Can anomaly detection identify problematic observations?
- Can sequence models improve prediction?

------------------------------------------------------------------------

## Can machine learning improve scientific measurement?

Rather than replacing observation, machine learning may improve it.

Questions include:

- Which observations should be collected next?
- Which instruments require recalibration?
- Which observations deserve human review?
- Can adaptive observation strategies increase scientific value?

------------------------------------------------------------------------

# Theme VII — Simulation

## Can realistic simulations reproduce the measurement process?

Simulation allows hypotheses to be tested under known conditions.

Questions include:

- Can simulated observers reproduce real measurement variability?
- Which sources of uncertainty are essential?
- Can inference methods recover known ground truth?
- Which methods remain robust under degraded conditions?

------------------------------------------------------------------------

# Theme VIII — Philosophy of Science

## What is the relationship between hypotheses, models, predictions, and observations?

Scientific reasoning depends on understanding the roles played by each.

Kepler seeks to make these relationships explicit.

Questions include:

- How do models connect hypotheses to observations?
- How should competing models be compared?
- When should a model be revised?
- What constitutes convincing evidence?

------------------------------------------------------------------------

## How is scientific knowledge constructed?

The project views science as an iterative process rather than a sequence of isolated discoveries.

Questions include:

- How do observations become evidence?
- How does evidence change beliefs?
- How does communication shape scientific understanding?
- How do communities converge on reliable explanations?

------------------------------------------------------------------------

# Theme IX — Scientific Communication

## How does writing influence scientific understanding?

Communication is not treated as the final stage of science.

Instead, it is part of scientific reasoning itself.

Questions include:

- Does writing improve observational quality?
- How does explanation refine understanding?
- How should uncertainty be communicated?
- Which forms of visualization best support inference?
- How do scientists persuade one another using evidence?

------------------------------------------------------------------------

# Enduring Principle

The questions collected here are intended to outlive any particular implementation.

Instruments will evolve.

Software will evolve.

Statistical methods will evolve.

Machine learning will evolve.

The scientific questions should remain stable.

Every new contribution to Kepler should ultimately help answer one or more of the questions described in this document.
