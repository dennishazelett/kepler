# Kepler 训练计划

## 目的

Kepler 训练计划旨在使参与者成为合格的科学观测者。

在参与任何研究之前，每位参与者都应具备必要的实践技能，以产出可复现、有完整记录且具备科学价值的观测。

训练计划与科学研究是有意分开设置的。

训练培养观测技能。

研究则运用这些技能去评估科学主张。

------------------------------------------------------------------------

# 理念

训练计划的目的不是教授天文学。

而是教授科学观测这门手艺。

参与者将学习如何进行审慎的测量、如何系统地记录、如何有效地传达，以及如何把这些成果贡献到不断积累的共享科学知识中。

无论所研究的科学主张是什么，这些技能都同样有价值。

------------------------------------------------------------------------

# 为什么训练要放在最前面

科学研究依赖于可靠的观测。

在追问一种科学解释是否优于另一种之前，参与者必须先能回答一些更基本的问题：

- 我如何描述我所观测到的现象？
- 我如何对它进行测量？
- 我如何估计不确定度？
- 我如何传达我的观测，使他人能够复现它？

在历史上，这些问题早在天文学成为一门预测性科学之前就已被解决。

Kepler 遵循同样的推进顺序。

------------------------------------------------------------------------

# 测量的作用

Kepler 项目建立在参与者自己产出的观测之上。

每一次观测都应当：

- 经过审慎的测量；
- 附有充分的元数据；
- 可被其他观测者复现；
- 得到永久保存。

后续研究的质量，直接取决于这些观测的质量。

正因如此，审慎的测量被视为一项科学技能，而不是一道预备性的技术练习。

------------------------------------------------------------------------

# 仪器的作用

训练计划假定参与者已能使用一件或多件与 Kepler 兼容的仪器。

仪器的制作、校准与维护在本仓库中另有文档说明。

训练计划的目的是教参与者如何有效地使用这些仪器，而不是如何制作它们。

随着仪器设计的演进，训练计划所培养的能力应保持稳定。

------------------------------------------------------------------------

# 训练计划的结构

每个训练模块都遵循统一的结构。

## 科学问题

模块从观测者会遇到的一个实际问题开始。

参与者由此了解到催生这项新技能的科学需求。

概念应当作为先前所遇问题的解决方案自然浮现，而不是作为孤立的知识点被引入。

------------------------------------------------------------------------

## 历史背景

在条件允许时，会介绍相关思想的历史发展脉络。

历史在这里不是作为背景资料，而是作为证据：参与者遇到的问题，正是早期观测者曾面对的同一批问题。

目标是理解科学思想为何被发明出来。

------------------------------------------------------------------------

## 实践技能

参与者学习并练习解决该问题所需的观测技能。

重点放在可重复性、审慎的测量与完整的记录上。

------------------------------------------------------------------------

## 反思

参与者需要思考：

- 需要哪些前提假设；
- 还残留哪些不确定度；
- 存在哪些局限；
- 这项新技能如何改进了科学观测。

反思被视为科学实践的组成部分，而非可选环节。

------------------------------------------------------------------------

## 能力考核

每个模块以一次实操的能力展示作为结束。

其目的不是考察记忆，而是验证参与者能否在野外实际运用这项技能。

------------------------------------------------------------------------

# 训练模块

初始训练计划由五个模块组成。

## 模块 1 —— 描述天空

**问题**

两位独立的观测者如何传达天空中同一个天体的位置？

参与者首先学习如何借助共享的观测参照来描述天体，之后再发展出正式的坐标系。

------------------------------------------------------------------------

## 模块 2 —— 测量天空

**问题**

如何把观测转化为定量的测量？

参与者学习使用 Kepler 仪器测量角度关系，并估计观测的不确定度。

------------------------------------------------------------------------

## 模块 3 —— 绘制天空

**问题**

一次次单独的测量，如何汇成一张共享的天图？

参与者学习重复测量如何确立一个共同的坐标框架，以及固定不动的天体如何成为后续观测所依据的参考系。

------------------------------------------------------------------------

## 模块 4 —— 运动的天空

**问题**

当观测在时间上重复进行时，会发生什么变化？

参与者开始记录太阳、月亮以及游移天体相对于既有天图的位置变化。

重点仍在描述，而非解释。

------------------------------------------------------------------------

## 模块 5 —— 贡献观测

**问题**

个人的观测如何成为科学数据？

参与者学习观测如何被记录、验证、整理并纳入 Kepler 数据集，从而可供未来的研究重复使用。

------------------------------------------------------------------------

# 结业

完成训练计划后，参与者应当能够：

- 产出可复现的天文观测；
- 使用本项目的测量框架传达观测结果；
- 记录不确定度与观测情境；
- 向共享的 Kepler 数据集贡献高质量的观测；
- 充分参与各项科学研究。

训练计划的完成，标志着从学习观测实践转向开展科学研究。

各项研究默认参与者已具备这些能力，因而聚焦于评估科学主张，而不再教授观测技术。

------------------------------------------------------------------------

# 设计原则

训练中引入的每一个概念，都应当解决参与者已经亲身遇到过的问题。

因此，只有当一个新想法成为做出更好观测的必要条件时，训练计划才会引入它。

参与者不必背诵科学术语。

他们需要理解的是：每个概念为何被发明出来，以及它如何改进科学实践。
